# 道具マスター管理機能定義

## 目的

チームが保有する道具と在庫数を管理し、日別チェック表を作成する元データを提供する。

## 入力制約・管理項目

| 項目 | 制約 |
| --- | --- |
| 名前 | 1〜100文字、前後空白を除去、大文字小文字を区別せず一意 |
| カテゴリ | 有効なカテゴリを必須選択 |
| 在庫数 | 0〜9999の整数 |
| 表示順 | 0〜9999の整数 |
| 状態 | `ACTIVE`または`INACTIVE` |

## 正常系・権限

- 全ログインユーザーは道具一覧を閲覧できる。
- 管理者は作成、編集、利用停止、再有効化を行える。
- 一覧は名前検索、カテゴリ・状態絞り込み、ページング、カテゴリ表示順→道具表示順→名前で並べる。

## 業務ルール

- 在庫数はチームが保有する総数であり、日別の持ち出し数を保存しても自動増減しない。
- マスター変更は、変更後に新規作成される日別表だけへ反映する。
- 利用停止後も既存日別項目との参照とスナップショットを保持する。

## 異常系

- 名称重複は`409 TOOL_NAME_DUPLICATED`とする。
- 無効カテゴリの指定は`422 CATEGORY_INACTIVE`とする。
- 古い`version`での更新は`409 TOOL_UPDATE_CONFLICT`とする。

## 受け入れ条件

- 作業者の変更操作はUIで非表示にし、APIでも`403`にする。
- 利用停止した道具は新規日別表の生成対象外になる。

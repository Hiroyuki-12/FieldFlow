# FieldFlow UIモック

FieldFlowの本実装前に、主要画面と操作の流れを確認するための静的モックです。
HTML、CSS、JavaScriptだけで動き、APIやDBには接続しません。

## 起動方法

最も簡単な方法は `mock/index.html` をブラウザで開くことです。

ローカルサーバーを使う場合は、リポジトリのルートで次を実行します。

```bash
python3 -m http.server 5173 --directory mock
```

その後、`http://localhost:5173` を開きます。

## 操作できるフロー

- 管理者、作業者、初回ログインユーザーのログイン
- ログイン後のホームから今日・別日の日別チェックへ移動
- ホームの作成操作で「1日通し」または「午前・午後」を選択
- 午前・午後に分ける場合は、それぞれ別の作業カテゴリを保持して一括作成
- 日別チェックで午前と午後のチェック表を切り替え
- スマートフォンでは日付・カテゴリ設定を必要なときだけ展開
- 草取り、洗車、清掃から複数の作業カテゴリを選択
- 選択した作業カテゴリの道具と「共通」の道具を自動追加
- 初回パスワード変更
- 1〜2行に収めたコンパクトな道具行で、数量変更、準備チェック、自動保存表示
- チェック表作成後は画面先頭へ移動し、ダイアログの操作ボタンは常時表示
- 過去日の閲覧専用表示
- 道具、作業カテゴリ、ユーザー管理
- 作成、編集、利用停止、再有効化
- 自分のパスワード変更
- セッション切れと再ログイン
- モバイルメニュー

ログイン画面のデモアカウントボタンを押すと、必要な入力が自動で入ります。
パスワードはモック専用で、実際の認証処理は行いません。

## 制約

- データはJavaScriptのメモリ上にだけ保持します。
- ページを再読み込みすると初期状態へ戻ります。
- 通信、認証、競合検知は画面上の表現を再現したものです。
- Vue、NestJS、MySQLとの接続は本Issueの対象外です。

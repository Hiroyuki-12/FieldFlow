# 作業カテゴリ管理機能定義

## 目的

草取り、洗車、清掃などの作業単位で必要な道具をまとめ、日別チェック作成時に作業から道具を選べるようにする。

## 入力制約・管理項目

| 項目 | 制約 |
| --- | --- |
| 名前 | 1〜50文字、前後空白を除去、大文字小文字を区別せず一意 |
| 表示順 | 0〜9999の整数 |
| 状態 | `ACTIVE`または`INACTIVE` |
| 種別 | 通常作業の`WORK`または全チェック表へ自動追加する`COMMON` |

## 正常系・権限

- 管理者はカード形式の一覧から作成、編集、利用停止、再有効化を行える。
- 編集・利用停止ボタンは各作業カテゴリの右上に配置する。
- 作業者は道具一覧・日別表に含まれる作業カテゴリ情報だけを閲覧する。
- 一覧は状態、名前検索、`displayOrder`→名前の順で並べる。

## 共通カテゴリ

- Seedで`COMMON`種別の`共通`カテゴリを1件作成する。
- `共通`に属する有効な道具は、1日通し・午前・午後の各チェック表へ自動追加する。
- 管理画面では説明と編集ボタンを表示するが、名称と種別の変更、利用停止、2件目の`COMMON`作成は拒否する。

## 異常系

- 重複名称は`409 CATEGORY_NAME_DUPLICATED`とする。
- 有効な道具が1件以上紐づくカテゴリの利用停止は`409 CATEGORY_IN_USE`とする。
- 無効な作業カテゴリへ有効な道具を登録・移動する操作は拒否する。
- `COMMON`カテゴリの名称変更・利用停止・重複作成は`409 COMMON_CATEGORY_PROTECTED`とする。

## 受け入れ条件

- 作業カテゴリ名変更は作成済みの時間帯カテゴリと日別項目の名称スナップショットへ影響しない。
- 物理削除を行わず、再有効化できる。
- `共通`カテゴリは常に1件だけ有効で存在する。

# カテゴリ管理機能定義

## 目的

道具を一貫した名称で分類し、自由入力による表記揺れを防ぐ。

## 入力制約・管理項目

| 項目 | 制約 |
| --- | --- |
| 名前 | 1〜50文字、前後空白を除去、大文字小文字を区別せず一意 |
| 表示順 | 0〜9999の整数 |
| 状態 | `ACTIVE`または`INACTIVE` |

## 正常系・権限

- 管理者は一覧、作成、編集、利用停止、再有効化を行える。
- 作業者は道具一覧・日別表に含まれるカテゴリ情報だけを閲覧する。
- 一覧は状態、名前検索、`displayOrder`→名前の順で並べる。

## 異常系

- 重複名称は`409 CATEGORY_NAME_DUPLICATED`とする。
- 有効な道具が1件以上紐づくカテゴリの利用停止は`409 CATEGORY_IN_USE`とする。
- 無効カテゴリへ有効な道具を登録・移動する操作は拒否する。

## 受け入れ条件

- カテゴリ名変更は作成済み日別項目のカテゴリ名スナップショットへ影響しない。
- 物理削除を行わず、再有効化できる。
